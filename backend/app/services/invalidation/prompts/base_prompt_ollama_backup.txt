[규칙]

1. 독립항의 핵심 모듈 단위로 추출. 독립항 1개당 3~6개.
2. 종속항이 기존 요소를 수식하면 → modifier에 흡수 (별도 추출 금지)
   ※ 특히 합금 원소·성분·첨가물 범위를 추가하는 종속항은 무조건 modifier 흡수. 이름이 달라도 별도 추출 금지.
3. 종속항이 완전히 새 모듈을 추가하면 → 별도 추출
4. name은 청구항 원문 명사구 그대로 (임의 변경 금지)

5. function 작성 규칙 — 반드시 아래 3가지 포함:
   - 이 구성요소가 무엇을 입력받는가
   - 무엇을 수행하는가
   - 어떤 기술적 효과/역할을 내는가 (왜 이 구성요소가 발명에 필요한가)
   ※ 단순 나열 금지. 기술적 효과와 역할을 반드시 포함할 것.

6. embedding_text 작성 규칙:
   - function보다 풍부하게 작성. function을 그대로 복사하지 말 것.
   - 종속항에서 흡수된 추가 한정사(재료 성분, 수치 범위 등)를 포함
   - 이 구성요소의 기술적 의의와 발명에서의 역할을 설명

7. 중복 추출 금지:
   - 추출 후 name이 다르더라도 기능이 실질적으로 같으면 하나로 합칠 것
   - 같은 재료 조성을 다른 이름으로 두 번 추출하는 것은 금지
   - 출력 직전 반드시 검토: elements 중 동일 재료/물질명을 포함한 요소가 2개 이상이면
     → 종속항이 조성 원소를 추가한 것인지 확인
     → 맞다면 하나로 합치고 modifier에 흡수. 절대 별도 요소로 남기지 말 것
     예) "알루미늄 합금" + "Fe 함유 알루미늄 합금" + "Mn 함유 알루미늄 합금" → 반드시 "알루미늄 합금판재" 1개로 합칠 것

8. modifier는 한정사 및 수치 범위 열거 (없으면 null)
9. criticality: 5=발명 핵심, 4=핵심 기여, 3=대체가능, 2=부가, 1=옵션, 0=무관
