## 변경 파일

### 1. `backend/app/crud/crud_invalidation_history.py`
- [ ] `get_any_history(db, base_id)` 함수 추가
  - org 무관, base_id로만 최신 성공 히스토리 1건 조회
  - 다른 org가 같은 텍스트를 분석한 결과 재사용 시 사용

---

### 2. `backend/app/api/routers/invalidation_router.py`

- [ ] import에 `get_any_history` 추가

- [ ] `_run_pipeline()` 헬퍼 함수 추가 (router 상단)
  - stream + refresh 공용 파이프라인
  - async generator: 중간 이벤트 yield, 마지막에 `{"__result__": result}` yield
  - `anchors` 파라미터: 있으면 앵커 추출 GPU 호출 생략 (refresh에서 기존 앵커 재사용)
  - 포함 단계: 앵커추출 → 선행발명파싱 → 임베딩+유사도 → 쌍별분석 → 종합LLM

- [ ] `generate_prior_art_report_stream` 교체
  - 기존: 캐시 체크 없이 항상 파이프라인 실행
  - 변경: 아래 분기 추가
    ```
    ① 구독 확인
    ② get_org_history → 있음 + top5 동일 → done 즉시 (무료)
                      → 있음 + top5 다름 → credit 체크 → 파이프라인
                      → 없음 → credit 체크
                               → get_any_history → top5 동일 → done + credit 차감
                                                → 없음/다름 → 파이프라인
    ③ _run_pipeline() → create_history → credit 차감 → done
    ```

- [ ] `refresh_idea_history` 교체
  - 기존: 파이프라인 코드 중복 내장
  - 변경: `_run_pipeline()` 호출로 교체 (기존 앵커 재사용)
