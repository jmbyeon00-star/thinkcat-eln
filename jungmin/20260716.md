## 현재 상황 (왜 고쳐야 하나)

어제(20260715) DB 모델을 새 구조로 전환했지만 그것만 완료됨:

```
models/invalidation.py  ← 이미 신규 모델(InvalTextCacheDB, InvalHistoryDB)로 교체됨 ✅
```

그런데 이걸 **사용하는 코드들이 아직 구 모델을 import** 하고 있어서
→ **현재 백엔드가 시작조차 안 되는 상태** (ImportError 발생)

구 모델 (이미 삭제됨):
- `InvalIdeaHistoryDB`, `InvalPriorArtReportDB`, `InvalPrepareCacheDB`
- `InvalElementDB`, `InvalAnalysisDB`, `InvalOverrideDB`, `InvalPairAnalysisDB`

### 3. `invalidation_router.py` ⬜

**무엇:** 라우터 전면 교체  
**왜:** 구 모델을 26줄에서 import하고 있어 백엔드가 죽어있음. 구 모델 기반 엔드포인트 16개 + 헬퍼 5개 제거 필요.

**제거 대상 (구 모델 의존):**
- 엔드포인트: `prepare-from-text`, `prepare-from-pdf`, `prior-art-report`(non-stream), `analysis/status`, `analysis/parse/base`, `analysis/parse/prior`, `analysis/run`, `analysis/overrides`, `analysis/{base_app_number}`, `analysis/{id}/interpretation`, `analysis/extract-from-claims`, `analysis/add-element`, `analysis/override`, `analysis/{base_app_number}/download`, `patents/{app_number}/elements`
- 헬퍼 함수: `_prepare_idea`, `_save_elements`, `_load_overrides`, `_apply_overrides`, `_run_greedy`, `_generate_interpretation`

**유지 대상:**
- `POST /analysis/prior-art-report/stream` — **재작성** (새 플로우)
- `POST /analysis/idea/history/{id}/refresh` — **재작성** (새 플로우)
- `GET /analysis/idea/history` — 신 CRUD 함수로 업데이트
- `GET /analysis/idea/history/{id}` — 신 CRUD 함수로 업데이트
- `DELETE /analysis/idea/history/{id}` — 신 CRUD 함수로 업데이트
- `GET /patents/info/{app_number}` — 변경 없음
- `GET /patents/{app_number}/claims` — 변경 없음

**추가:**
- `POST /analysis/extract-pdf-text` — PDF 텍스트 추출만 (LLM 없음, 구 prepare-from-pdf 대체)

**stream 엔드포인트 새 payload:**
```
기존: {idea_uuid, base_id, raw_text, full_text, prior_app_numbers, model, idea_title}
신규: {raw_text, model, section}
```

**stream 내부 새 플로우 요약:**
```
base_id = "txt_" + md5(raw_text)[:16]
① check_subscription
② INVAL_TEXT_CACHE_TB 확인
   ├─ 캐시 없음 → check_credits → GPU /prepare → save_text_cache → 파이프라인 → create_history → decrement_credit
   └─ 캐시 있음 → [GPU /refresh + get_org_history] 병렬
        → top5 동일 → 기존 결과 반환 (무료)
        → top5 다름 → check_credits → 파이프라인 → update_history → decrement_credit
```

**SSE 이벤트 추가:**
```
prepare_done: {base_id, candidate_patents(15개), refined_title, prior_app_numbers(5개)}
anchor_done:  기존과 동일
done:         result에 candidate_patents 포함
```
